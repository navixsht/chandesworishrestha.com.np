# Nabin Shrestha — Network Engineer Website

A lightweight, responsive static website inspired by the structure and clean portfolio style of the referenced site, but written from scratch for an ISP/network-engineering profile.

## Files
- index.html
- style.css
- script.js

## Publish on Mercantile hosting
Upload all three files to your public web directory (commonly `public_html`) and make sure `index.html` is in the document root.

## Important
1. Replace the email address in `index.html` if needed.
2. The contact form is front-end only. Connect it to your preferred form/email service or backend before using it.
3. The site uses Google Fonts via an external CSS import. If you want a fully offline version, replace the font import with local fonts.
